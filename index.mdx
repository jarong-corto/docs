The Corto Developer Console lets you build and publish Applications that extend Corto. Once an Application is approved and live, it appears in the Corto Marketplace, where firms can install it and use it directly inside Corto.

## Get started

<Card title="Quickstart" icon="rocket" horizontal href="/quickstart">
  Sign up, create your first Application, and take it from draft to live.
</Card>

## Application types

<CardGroup cols={3}>
  <Card title="Frontend Application" icon="globe" href="/auth/apps/frontend">
    Add actions to the Corto interface at the firm or matter level.
  </Card>

  <Card title="Backend Application" icon="database" href="/auth/apps/backend">
    Connect your server to the Corto public APIs.

  <Card title="MCP Application" icon="plug" href="/auth/apps/mcp">

</CardGroup>

## Environments

| Environment | Purpose | Approval required |
| --- | --- | --- |
| Sandbox | Development and testing with [Test Accounts](/test-accounts). No access to production data or live users. | No |
| Production | A live environment with access to real data. Listed in the Marketplace once published. | Yes |
