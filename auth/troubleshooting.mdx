---
title: "Troubleshooting"
description: "Solutions to common issues in the Corto Developer Console."
---

<AccordionGroup>
  <Accordion title="I can't create Applications after signing up">
    New developer accounts must be approved by a Corto admin before you can create Applications. If your account has been pending for a while, contact the Corto Backend team.
  </Accordion>

  <Accordion title="My Sandbox Application doesn't appear in Corto">
    Check that the user you're testing with is added under [Test Accounts](/test-accounts) and already has a Corto, LawY, or AccTivity account.
  </Accordion>

  <Accordion title="My changes aren't showing in the live Application">
    Draft changes only apply when you select **Set live**. Make sure your Application has been approved, then set it live.
  </Accordion>

  <Accordion title="My MCP Application isn't available in chat">
    Users must first connect the Application under **Account settings** > **Integrations**, then turn it on in chat under **Toggle features**.
  </Accordion>
</AccordionGroup>

## Get help

If your issue isn't listed here, contact the Corto Backend team.
