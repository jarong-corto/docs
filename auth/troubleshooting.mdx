<AccordionGroup>
  <Accordion title="I can't create apps after signing up">
    New developer accounts must be approved by a Corto admin before you can create apps. If your account has been pending for a while, contact your Corto representative.
  </Accordion>

  <Accordion title="My sandbox app doesn't appear in Corto">
    Check that the user you're testing with is added under [Test accounts](/test-accounts) and already has a Corto, LawY, or AccTivity account.
  </Accordion>

  <Accordion title="My changes aren't showing in the live app">
    Draft changes only apply when you select **Set live**. Make sure your app has been approved, then set it live.
  </Accordion>

  <Accordion title="My MCP app isn't available in chat">
    Users must first connect the app under **Account settings** > **Integrations**, then turn it on in chat under **Toggle features**.
  </Accordion>
</AccordionGroup>
